If a station has $< 10$ years of coverage or does not measure the chosen parameter, the engine transparently falls back to NASA POWER and labels the exact source used.Step 2: HOW MUCH? — Ordinary Least Squares (OLS) SlopeWe fit a least-squares linear regression over valid years $t_i$ and values $y_i$:$$\beta_1 = \frac{\sum_{i=1}^{n} (t_i - \bar{t})(y_i - \bar{y})}{\sum_{i=1}^{n} (t_i - \bar{t})^2}$$We report both the decadal rate of change ($10 \cdot \beta_1$) and the total change across the observed record.Step 3: REAL OR NOISE? — Tie-Corrected Mann-Kendall TestBecause climate data (especially desert rainfall) is often skewed and non-normal, ECO DRIFT uses the non-parametric Mann-Kendall trend test:Kendall Score ($S$): Compares every year with every subsequent year:$$S = \sum_{i=1}^{n-1} \sum_{j=i+1}^{n} \text{sgn}(y_j - y_i)$$Tie-Corrected Variance: Accounts for tied annual values ($q$ tied groups of size $t_p$):$$\text{Var}(S) = \frac{n(n - 1)(2n + 5) - \sum_{p=1}^{q} t_p(t_p - 1)(2t_p + 5)}{18}$$Standardized $Z$-Statistic & Two-Tailed $p$-Value:$$Z = \begin{cases} \frac{S - 1}{\sqrt{\text{Var}(S)}} & \text{if } S > 0 \\ 0 & \text{if } S = 0 \\ \frac{S + 1}{\sqrt{\text{Var}(S)}} & \text{if } S < 0 \end{cases}$$Using a 1,000-slice midpoint Riemann integration of the standard normal density, we compute $p = 2 \left(1 - \Phi(\vert{}Z\vert{})\right)$. A trend is declared REAL if and only if $p < 0.05$ (less than a $5\%$ probability of occurring by random chance).Step 4: Honest Scientific LimitsDetection $\neq$ Attribution: Our statistical test proves whether a variable is changing, not why.
